# Progressive Chat

An ecosystem of intelligent communication tools — improving private and
public interactions through automated self- and organization management.

We implement the Matrix protocol end-to-end (homeserver, clients,
bridges, bots, SDKs) plus focused apps for chats, forums and conferences.

**Mission:** fast, functional software without unnecessary overhead.

**Stack:** C++20/23 across core, homeserver, CLI and thin clients;
Kotlin on Android. All projects are Free Software.
